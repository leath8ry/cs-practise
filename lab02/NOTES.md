Git: основные понятия



Рабочая папка - это папка на вашем компьютере, где вы редактируете файлы. Здесь находятся текущие версии файлов проекта, которые вы можете изменять. Любые изменения здесь ещё не отслеживаются Git.



Индекс — это промежуточная область между рабочей папкой и коммитом. Когда вы выполняете `git add`, файлы попадают в индекс. Это позволяет выбрать, какие именно изменения войдут в следующий коммит. Индекс показывает, что будет включено в коммит.



Коммит — это снимок состояния проекта в определённый момент времени. Он сохраняется в истории Git навсегда. Каждый коммит имеет уникальный ID, сообщение, автора и дату. Коммиты формируют историю изменений проекта.




Различия между Git и GitHub


Git — это система контроля версий, программа, которая устанавливается на ваш компьютер. Она отслеживает изменения в файлах, позволяет создавать коммиты, ветки и управлять историей проекта локально.

GitHub — это веб-сервис, который хранит репозитории Git в интернете. GitHub предоставляет интерфейс для работы с Git-репозиториями, позволяет сотрудничать с другими разработчиками, отслеживать задачи и многое другое.



Использованные команды:

git status — показывает состояние рабочей папки и индекса. Какие файлы изменены, какие добавлены в индекс, какие не отслеживаются. Помогает понять, что происходит в репозитории прямо сейчас.

git diff — показывает различия между рабочей папкой и индексом. То есть изменения, которые ещё не добавлены командой `git add`. Позволяет увидеть, что именно вы изменили в файлах.

git diff --staged — показывает различия между индексом и последним коммитом. То есть изменения, которые уже добавлены в индекс и готовы к коммиту. Помогает проверить, что именно войдёт в следующий коммит.
