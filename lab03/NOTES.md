git diff - показывает что изменено, но не добавлено. Сравнивает рабочую папку с индексом

git show - выводит данные коммита и его изменения относительно родителя

git log - путь оставляет только коммиты, которые меняли этот файл



log -S - нашёл коммиты, где появлялись новые функции (ключевое слово "def")

blame - показал, какая строка была добавлена в каком коммите и кем
